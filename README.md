# OTPUS
OTP encryption between two devices.
To use this OTP you need the full self contained folder.



HOW TO USE:



Version 5 (Latest) --  

- You need to have python 3.5 and preinstalled modules to run this version.
- Download the OTPE_v5 folder
- The system only supports a single line of communication, you can send one message then receive one, you cannot send 2 messages in a row.


- TO SEND A MESSAGE:

- Type your message into MAILBOX.txt
- Run the python application
- A .txt file called NEW MESSAGE.txt will be generated
- send this text file containing the encrypted hex message to the recipient


- TO RECEIVE A MESSAGE:

- Take the message file and place it into the main folder
- Run the application
- The message will now be written to MAILBOX.txt


- TO LOAD A NEW IMAGE:

- Navigate to the 'photo album' Folder
- Run the python application called 'Picture Loader'





Version 2   --

- Compatible with standard python and terminal based. Drag the file into your directory and run the .exe file, the result should be automatically saved to your clipboard.
